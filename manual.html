日本語

このマニュアルは、Q-Pulse の日常的な使い方を説明します。毎日長い日報を書く必要はありません。タスクを作成し、必要な時だけ実績を更新してください。

画面の見方

主なメニュー

メニュー用途
今日期限超過、今日の期限、7日以内の対応を確認します。
タスク担当者ごとの作業、期限、実績を管理します。
プロジェクト進捗、残り日数、責任者、プロジェクト内の負荷を確認します。
作業実績・メモ入力した実績工数と作業内容の履歴です。
メンバーKPI担当タスク、期限遵守、負荷、実績記録を確認します。
基本ルール

使い分け

  1. 改善、新規立上げなどは プロジェクト を作成します。
  2. 実際に行う作業は、そのプロジェクトに紐づけて タスク として登録します。
  3. 作業したら、タスクの 実績を更新 から時間を追加します。
  4. 本当に完了した時だけ状態を 完了 にします。

1. プロジェクトを登録する

1
プロジェクト を開き、＋ 新規プロジェクト を押します。
2
プロジェクト名、責任者、期限、初期進捗率、健全性、目的・KPI を入力します。
3
初期進捗率は、すでに進んでいる既存案件のための数値です。新しい案件は 0% で開始します。
健全性：順調 は通常、要注意 は遅延・品質・設備などのリスクがある状態です。要注意のプロジェクトは通知対象になります。

2. タスクを登録する

1
タスク から ＋ 新規タスク を押します。プロジェクト画面の このプロジェクトにタスクを追加 からも登録できます。
2
プロジェクト、主担当者、期限、予定工数、優先度、状態を選びます。
3
支援メンバーがいる場合は 支援メンバー に追加します。予定工数は担当者と支援メンバーで均等に負荷へ配分されます。
期限のルール：タスク期限は、プロジェクト期限を超えて設定できません。

3. 実績工数を入力し、進捗を自動更新する

1
対象タスクの 実績を更新 を押します。
2
作業者、今回の実績工数（時間）、必要なら 作業内容 を入力して保存します。
3
システムが入力済み工数を合計し、実績工数 ÷ 予定工数 でタスク進捗率を自動計算します。プロジェクト進捗も自動更新されます。
例表示結果
予定工数 4時間、今回 1時間を入力実績 1h / 4h ・進捗 25%
次回さらに 1時間を入力実績 2h / 4h ・進捗 50%
重要：予定工数と同じ時間を入力しても、自動で 完了 にはなりません。作業が本当に終わったことを確認してから、状態を 完了 に変更してください。

4. 突発対応・作業の中断

設備故障・品質不良など

ダッシュボードの 緊急対応 から新規タスクを作成します。緊急対応の種類と影響内容を入力し、主担当者を指定してください。

作業を中断する場合

元のタスクは 進行中 のままでも構いません。作業内容に「設備故障のため中断」「材料待ち」など短く記録してください。再開時は同じタスクへ実績時間を追加します。

5. 管理者・マネージャーが確認する項目

作業負荷

ダッシュボードとメンバー画面で、未完了タスクの予定工数と週の容量を比較します。容量を超える場合は、支援メンバーを追加するか、期限・優先度を見直します。

通知とCSV

期限が近いタスクと要注意プロジェクトは通知対象です。プロジェクト、メンバー、作業実績は各画面の CSV ボタンから出力できます。

よくある質問

質問回答
毎日日報を入力する必要がありますか？ありません。作業した時、進捗が変わった時、または問題が起きた時だけ記録します。
進捗率が手入力と違います。実績工数を入力すると自動進捗が反映されます。既存プロジェクトの初期進捗率は下がりません。
画面が古い、または表示がおかしい。Ctrl + F5 で再読み込みしてください。改善しない場合は、スクリーンショットと操作内容を管理者へ共有してください。

English

This manual explains everyday use of Q-Pulse. Long daily reports are not required. Create tasks and record actual work only when needed.

Basic rule

How the records work

  1. Create a project for an improvement, launch, or other initiative.
  2. Create tasks for the work to be performed within that project.
  3. Use Update actual to add hours when work is performed.
  4. Set a task to Done only after the work is truly complete.

1. Create a project

1
Open Projects and select + New project.
2
Enter the project name, responsible person, deadline, initial progress, health, and objective or KPI.
3
Use initial progress only for existing work that was already underway. Start a new project at 0%.
Health: use On track for normal work and At risk when there is a schedule, quality, equipment, or other risk. At-risk projects are included in alerts.

2. Create a task

1
Open Tasks and select + New task. You may also use Add task to this project from a project card.
2
Select a project, primary owner, due date, planned hours, priority, and status.
3
Add support members when needed. Planned hours are split equally across the primary owner and support members for workload calculation.
Deadline rule: a task due date cannot be later than its project deadline.

3. Add actual hours and update progress automatically

1
Select Update actual on the relevant task.
2
Enter the worker, hours worked in this update, and an optional short work note. Save the record.
3
Q-Pulse totals all recorded hours and calculates task progress as actual hours ÷ planned hours. Project progress updates automatically.
ExampleResult
Planned hours: 4; add 1 actual hourActual 1h / 4h · Progress 25%
Add another 1 hour laterActual 2h / 4h · Progress 50%
Important: entering hours equal to planned hours does not automatically set the task to Done. Confirm completion first, then change the status manually.

4. Emergency work and interruptions

Machine breakdown or quality issue

Use Emergency response on the dashboard to create a new urgent task. Select the emergency type, impact, and responsible person.

Interrupted work

The original task may remain In progress. Add a short note such as “paused due to machine breakdown” or “waiting for material”. Add actual hours to the same task when work resumes.

5. What managers should review

Workload

Use the dashboard and Members screen to compare open planned hours with weekly capacity. Add support, revise priorities, or adjust dates when capacity is exceeded.

Alerts and CSV reports

Tasks nearing their due date and at-risk projects are alert candidates. Export project, member, and actual-work data with the CSV buttons on each screen.
